{%- comment -%} The topper under the header. Param: hero (front matter: src, width, height, alt). With no hero.src it renders a placeholder in the same spot and shape, so every page has the slot. To fill it, add to the page's front matter (alt text is written by a person; TK until then): hero: src: some-photo.jpg width: 1600 height: 1067 alt: TK Optional `position:` (CSS object-position for the crop, default "50% 50%") `mobile_ratio:` (CSS aspect-ratio below 640px wide, e.g. 4 / 5; default --hero-ratio-mobile) and `mobile_zoom:` (scale about the position point below 640px; 1 = none, 1.2 = 20% closer) let each page frame its photo; desktop keeps the aspect ratio. An optional `caption:` (e.g. a photo credit) shows under the image, right-aligned. Pass hero=false (front matter `hero: false`) for pages that shouldn't have one. {%- endcomment -%} {%- if include.hero != false -%} {%- endif -%}
