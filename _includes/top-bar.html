{%- comment -%} The fixed top bar: the logo tab and rule (tab.html) plus the page links on a translucent, blurred bar. Params: page_content (the page's rendered HTML, to read section headings from on story pages). Items come from _data/navigation.yml (disabled ones are skipped). Wide screens: the links split around the tab, half on each side, built outward from the tab. Narrow screens: the current page with a chevron (just the chevron on the home page); opening it lists the others (assets/js/top-bar.js). The nav comes before the tab so the tab paints over it. The home page is mostly a recirculation page, so it gets no links: just the tab and rule, centered at every size (.site-top--solo). On story pages the bar holds a second set of links, the page's own sections (generated from its

headings by section-headings.html). One set shows at a time, chosen by data-mode: the pages, until the story's first divider has scrolled away; then the sections, with scroll-spy. Same markup, same styling, different links. {%- endcomment -%} {%- assign bar_items = site.data.navigation | where_exp: "item", "item.disabled != true" -%} {%- assign bar_split = bar_items.size | plus: 1 | divided_by: 2 -%} {%- assign bar_current = "" -%} {%- for item in bar_items %}{% if page.url == item.url %}{% assign bar_current = item.label %}{% endif %}{% endfor -%} {%- assign bar_sections = false -%} {%- if page.layout == "story" -%} {%- include section-headings.html page_content=include.page_content -%} {%- if nav_ids.size > 0 %}{% assign bar_sections = true %}{% endif -%} {%- assign sec_split = nav_ids.size | plus: 1 | divided_by: 2 -%} {%- endif -%}
